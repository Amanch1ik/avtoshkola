# АвтоПрофи — веб-приложение автошколы

Курсовая работа по дисциплине «Web-технологии».  
Разработал: Орозганов Расул, группа ПИН-2-24, КГТУ им. И. Раззакова.

## О проекте

Клиентский прототип сайта для автошколы «АвтоПрофи» (г. Бишкек).  
Реализованы 7 страниц: главная, курсы, расписание, инструкторы, запись на курс, авторизация и личный кабинет ученика.

Функциональность:
- просмотр курсов по категориям A, B, C, D с ценами и программами
- расписание занятий с фильтрацией по инструктору
- онлайн-форма записи с валидацией
- вход и регистрация (Bootstrap Tabs)
- личный кабинет: прогресс обучения, ПДД-тест, занятия, оплата
- адаптивная вёрстка от 375px до 1920px

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные, медиазапросы)
- Bootstrap 5.3
- Bootstrap Icons 1.11
- JavaScript ES6+ (без фреймворков)

## Запуск

Проект статический — сборка не нужна.

1. Скачать репозиторий:
```
git clone https://github.com/Amanch1ik/avtoshkola.git
```

2. Открыть `index.html` в браузере — либо двойным кликом, либо через Live Server в VS Code.

Интернет-соединение нужно только для загрузки Bootstrap и иконок (подключены через CDN).

## Структура файлов

```
avtoshkola-repo/
├── index.html          — главная страница
├── courses.html        — курсы
├── schedule.html       — расписание
├── instructors.html    — инструкторы
├── register.html       — запись на курс
├── login.html          — авторизация
├── cabinet.html        — личный кабинет
├── css/
│   └── style.css       — все стили проекта
└── js/
    └── main.js         — вся логика (навигация, формы, фильтры, тест)
```

## Примечание

Серверная часть не реализована. Формы симулируют отправку, авторизация перенаправляет на страницу кабинета. Проект является frontend-прототипом.
